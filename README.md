T5 - Do-file automatizado

Para reutilizar el do-file con otros datos, solo hace falta editar los parámetros
que se establecen al principio, ya que todo lo demás está automatizado de acuerdo
a estos parámetros.

## Cómo correrlo

Abrir STATA y ejecutar `scripts/tarea_t5.do`
